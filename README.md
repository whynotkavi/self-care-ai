\# Self-Care AI 🌱



An AI companion for self-care that understands how you feel.



\## Features

\- Emotion understanding (fine-tuned DistilBERT, 6 emotions)

\- BMI calculator from user input

\- Sleep schedule manager

\- Skincare suggestions

\- Workout routine planner

\- To-dos and deadline tracker

\- Habit tracker



\## How it works

\- \*\*Brain:\*\* a small pretrained model fine-tuned to detect emotions

\- \*\*Hands:\*\* plain Python tools for BMI, sleep, to-dos, deadlines, habits

\- \*\*Chatbot:\*\* joins both, so replies match the user's mood
